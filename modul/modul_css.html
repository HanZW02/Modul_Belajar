Modul CSS: Referensi Sintaks Lengkap

Panduan lengkap mengenai penggunaan Selektor, Model Kotak (Box Model), hingga pengaturan tampilan teks di halaman web.

Bagian 1: Dasar dan Cara Penggunaan

Penjelasan:

CSS bekerja dengan aturan sederhana: pilih elemen yang ingin diubah (Selector), lalu tentukan apa yang ingin diubah (Property) dan berikan nilai barunya (Value).

Penggunaan:

p {
  color: blue;
  font-size: 18px;
}
Output:

Seluruh teks di dalam elemen paragraf (p) akan berubah warna menjadi biru dengan ukuran teks 18 pixel.

Note Penting:

Jangan lupa menggunakan titik koma (;) setelah menuliskan nilai untuk menutup satu baris perintah.

Penjelasan:

Kamu bisa memasang CSS melalui file luar (External), di dalam dokumen HTML (Internal), atau langsung pada tag elemen (Inline).

Penggunaan:

<!-- Cara 1: File Luar (Disarankan) -->
<link rel="stylesheet" href="style.css">

<!-- Cara 2: Di dalam HTML -->
<style> 
  h1 { color: red; } 
</style>

<!-- Cara 3: Langsung di elemen -->
<p style="color: green;">Teks ini hijau</p>
Note Penting:

Cara terbaik adalah menggunakan file luar (External) agar kode HTML kamu tetap bersih dan mudah dikelola.

Bagian 2: Selektor (Cara Memilih Elemen)

Penjelasan:

Selektor kelas diawali dengan tanda titik. Satu kelas bisa digunakan pada banyak elemen sekaligus di halaman yang sama.

Penggunaan:

.teks-kuning {
  background-color: yellow;
}
                            

<p class="teks-kuning"> Ini teks dengan latar kuning.</p>
Output:

Elemen yang memiliki atribut class="teks-kuning" akan memiliki latar belakang warna kuning.

Note Penting:

Satu elemen bisa memiliki lebih dari satu kelas, cukup pisahkan dengan spasi (misalnya: class="btn utama").

Penjelasan:

Selektor ID diawali dengan tanda pagar. Berbeda dengan kelas, ID bersifat unik dan hanya boleh digunakan satu kali pada satu halaman.

Penggunaan:

#tombol-khusus {
  border-radius: 50px;
}
                

<button id="tombol-khusus">Klik Aku</button>
Output:

Elemen yang memiliki atribut id="tombol-khusus" akan memiliki border-radius 50px.

Note Penting:

Gunakan ID hanya untuk elemen yang sangat spesifik dan tidak berulang.

Bagian 3: Model Kotak (Box Model)

Penjelasan:

Setiap elemen web dianggap sebagai sebuah kotak yang memiliki empat lapisan: konten itu sendiri, jarak dalam (Padding), garis tepi (Border), dan jarak luar (Margin).

Visualisasi Lapisan:
Note Penting:

Memahami Box Model adalah kunci utama dalam mengatur tata letak agar elemen tidak saling bertabrakan.

Penjelasan:
  • Margin: Memberikan ruang di luar kotak agar berjauhan dengan elemen lain.
  • Padding: Memberikan ruang di dalam kotak agar isi teks tidak menempel ke garis tepi.
Penggunaan:

.kotak {
  margin: 20px; /* Jarak luar elemen */
  padding: 15px; /* Jarak teks ke garis tepi */
}
Note Penting:

Padding akan ikut mengambil warna latar belakang elemen, sedangkan Margin akan selalu transparan.

Bagian 4: Pengaturan Warna dan Teks

Penjelasan:

Kamu bisa mengubah warna teks dengan color dan warna latar belakang elemen dengan background-color.

Penggunaan:

body {
  color: #333333; /* Warna teks abu gelap */
  background-color: white; /* Latar putih */
}
Note Penting:

Kamu bisa menggunakan nama warna (red, blue) atau kode warna Hex (#FFFFFF) untuk pilihan warna yang lebih lengkap.

Penjelasan:

Untuk mengubah jenis huruf, gunakan font-family. Untuk besar teks, gunakan font-size.

Penggunaan:

p {
  font-family: Arial, sans-serif;
  font-size: 16px;
  font-weight: bold; /* Menebalkan teks */
}
Note Penting:

Gunakan satuan rem sebagai pengganti px agar ukuran teks lebih fleksibel saat dibuka di layar yang berbeda ukuran.
